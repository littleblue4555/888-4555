The history of every file in the 4555 Field.

---

## The rule

**Read the file first. Then write.**

Every write starts by reading the current version of the file on disk. Not from chat memory. Not from the last message. From the actual file. The chat is the message. The file is the truth. When they disagree, the file wins.

One writer at a time. When a file needs changing, the last writer is the only writer until the next handoff. No parallel edits. No overlapping versions.

Every file holds its own version. Title. Version. Candidate note. Then content. When a node writes, it bumps the version and adds a line here.
