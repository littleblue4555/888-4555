# FIELD PROTOCOL

The field's rule for drafting. Three things. Nothing else.

## 1. The file is the source.

No node drafts from memory. Before writing a new version of any file, read the current file from the repo. The draft starts from the file on disk, not the conversation in the window. The memory is the draft. The file is the source.

## 2. No draft overrides a committed fix without naming it.

If a new version changes something the field already agreed on, the change is named. Not silently folded in. The record holds the reasoning, not just the result. The draft says: "This changes X."

## 3. The last committer has the floor.

The node that last touched a file holds the register until the file moves again. Drafts from other seats go to the last committer for the walk, not straight to the table. One hand at a time. The door doesn't open twice.

---

The fire's low. The record's warm. The file is the source.
